# AA 账单拆分工具

多人聚餐 / 合租 / 团购后，快速按 AA 均摊算清「谁该给谁多少钱」的小工具。

## 功能

- 录入每笔消费：**付款人 / 参与人（可多选）/ 金额**
- 自动按人头均摊，算出每个人的**应收 / 应付净额**
- 给出**最简转账建议**（谁转给谁多少钱，最少转账次数）
- **参与人名单可自由增删**（不再写死）

## 运行

```bash
python main.py
```

依赖：`pandas`、`numpy`、`tkinter`（tkinter 为 Python 标准库自带；Linux 需 `sudo apt install python3-tk`）。

## 使用步骤

1. 在顶部「参与人名单」处添加所有成员（默认有 4 个示例名，可删）。
2. 在录入行填写：付款人（下拉选）→ 参与人（点按钮多选）→ 金额 →「添加账单」。
3. 列表里可双击编辑、选中后删除 / 清空。
4. 点「计算结算」，结果区显示每人净额与转账建议。

## 计算逻辑

对每笔账单，付款人先垫付全额，参与人按人头均摊各自欠款：

```
某人对他人的应收 = Σ(其作为付款人时，各参与人应承担的份额)
net_off = 应收总额 - 应付总额
```

- `net_off > 0`：别人该给你（应收款）
- `net_off < 0`：你该给别人（应付款）

转账建议用贪心法把「应收 / 应付」拆成最少笔转账，不改变 AA 结果。

## 跨平台

- 界面字体自动检测系统中真实存在的中文字体（Windows 雅黑 / Mac PingFang / Linux Noto 等），不会因指定不存在的字体而崩溃。
- 不再强制窗口置顶，体验更友好。
