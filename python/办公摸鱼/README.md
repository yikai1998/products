# 企业微信「保活」小工具

用 `pyautogui` 每 3 分钟自动在当前窗口输入并删除 `Hi Team,`，防止企业微信因长时间无操作被判定为「离开」状态。

> 这是一个**后台自动化脚本**，不是交互式 GUI 程序——它的工作就是替你在输入框里打字，因此刻意不做图形界面（做界面反而会和打字抢焦点）。

## 原理

1. 启动前提示：请先把企业微信对话框置于最前（脚本会往「当前焦点窗口」打字）。
2. 15 秒倒计时后进入循环，共 100 轮（约 5 小时）。
3. 每轮：输入 `Hi Team,` → 停约 2 秒 → 按 8 次 Backspace 删除 → 等 3 分钟。

## 运行

```bash
pip install pyautogui
python wecom_v1.py
```

## ⚠️ 安全与注意

- **紧急停止**：脚本已开启 `pyautogui.FAILSAFE`（默认开启）。运行时把鼠标**快速甩到屏幕任意一个角落**即可立即中止。
- 它会向「当前焦点窗口」输入文字，**务必确认焦点在企业微信输入框**，否则可能误输入到别处。
- 仅用于本人账号的合规场景，勿用于绕过公司考勤/监控等违规用途。
- `pyautogui` 在 Windows / macOS / Linux 均可运行（Linux 需 `sudo apt install scrot python3-tk` 等依赖）。
- 逻辑保持原作者版本不变，仅将源码由 GBK 转为 UTF-8 以适配 GitHub。
