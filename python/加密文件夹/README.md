# U 盘文件夹「伪装加密」助手

把指定文件夹伪装成 Windows 的「控制面板」系统文件夹并隐藏，达到防误翻/防手贱的目的。

> 按需求**未做图形界面、未改逻辑**（保持原脚本）。

## 原理

- 利用 Windows 特殊的 CLSID：`{21EC2020-3AEA-1069-A2DD-08002B30309D}`（即「控制面板」的类 ID）。
- 把文件夹重命名为 `MyPrivateData.{21EC2020-3AEA-1069-A2DD-08002B30309D}`，再用 `attrib +h +s` 设为**系统 + 隐藏**属性。
- 资源管理器里即使勾选「显示隐藏文件」也看不到它，必须专门取消「隐藏受保护的操作系统文件」才会露出来。

## 运行（仅 Windows）

```bash
python locker.py
```

选择 `1` 解锁（取消隐藏并还原原名）或 `2` 锁定（隐藏伪装）。

## ⚠️ 重要说明

- **这是「隐藏」不是真正加密**：不设密码也能被懂行的人打开，且密码 `PASSWORD` 直接写在源码里（请自行修改）。请勿用于存放真正敏感的数据，重要资料请使用 BitLocker / VeraCrypt 等真加密。
- 仅依赖 `attrib` 与 CLSID，**Windows 专属**，在 macOS / Linux 上无意义。
- 跨设备（如换电脑）记得连同文件夹一起拷贝，重命名逻辑依赖同一 CLSID。
