# 古龙小说下载

把古龙作品的章节批量抓取并合并为 txt 电子书。

## 两个下载源

| 来源 | 脚本 | 适用 | 保存目录 |
|------|------|------|----------|
| 努努书坊 | `nunu.py` | 外网环境 | `Downloads/` |
| 古龙武侠网 | `gulongbbs.py` | 非外网环境 | `Downloads/` |

> 两个来源现在统一保存到**脚本所在目录下的 `Downloads/`**（绝对路径，不受你从哪个目录启动影响；不再分 `Downloads` 与 `Downloads2`）。若你本地已有旧的 `Downloads2/` 文件夹，把里面的 txt 手动合并进 `Downloads/` 后即可删除。

## 运行

```bash
python main.py          # 图形界面（默认）：选来源、勾书目 / 填代码、看实时进度
python main.py --cli    # 命令行交互模式（沿用原流程）
```

## 功能（界面）

- 选择下载源
- 努努：一键「获取作品列表」→ 列表多选 → 下载
- 古龙武侠网：填写书籍代码（如 `ssydj`，多个用逗号分隔）→ 下载
- 实时进度日志（复用下载核心的 `print` 输出）
- 一键打开下载目录
- **底部三个按钮固定在窗口底部**，默认尺寸下即可完整看到（不再被上方列表/日志挤出可视区）
- 下载时下载按钮会置灰，避免重复点击

## 关于线程安全（重要）

下载在后台线程执行，但 **Tkinter 只能在主线程触碰**。旧版在子线程里直接弹 `messagebox`、调 `root.after`，是
`Fatal Python error: PyEval_RestoreThread ... GIL is released` 这类崩溃的典型成因。现改为：

- 校验与弹窗全部留在主线程；
- 日志通过线程安全 `queue.Queue` 传递，由主线程定时轮询刷新；
- 结果回填 / 按钮状态恢复统一用 `root.after(0, ...)` 调度回主线程。

- 下载逻辑完全保留在 `nunu.py` / `gulongbbs.py` 中，本 `main.py` 只做入口与界面封装，未改动抓取/解析代码。
- 小说网站结构可能变化，若解析失效需同步更新对应模块的选择器。
