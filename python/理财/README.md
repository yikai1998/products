# 基金走势分析（个人理财）

一个用于分析公募基金走势的小工具：自动抓取净值 / 持仓 / 基本信息，计算均线、历史估值分位、
回撤、连涨连跌等因子，给出**统一的「7 档估值结论」**（严重高估 / 高估 / 估值偏高 / 合理 /
估值偏低 / 低估 / 严重低估，适用于所有类型基金），并用图形界面管理自选基金、批量分析、
生成带日期筛选的可交互走势图。

## 功能

- **图形界面（`gui.py`）**：增 / 删自选基金、分类（持仓 / 临时 / 自选 / 观察 / 其它）；
  单只基金设「今日预测涨幅」；一键批量或单只分析（后台线程，界面不卡）；
  列表直接看「类型 / 最新净值 / 成本价 / 浮动盈亏 / 估值分位 / 估值结论 / 预测% / 上次更新」；双击打开报告。
- **持仓成本与浮动盈亏**：单选一只基金点「💰 设成本」录入成本单价与可选份额，
  列表实时显示盈亏，报告顶部显示成本/盈亏卡片并在净值图上画一条成本水平线；数据存 `持仓成本.json`（不入库）。
- **分类标签可改名 / 转移**：点「🏷 管理分类」可直接改标签名、新增标签、删除空标签
  （改名只改 `categories.json` 与 `funds.json` 内字段，不影响其它文件）；选中基金后点「🔁 转移分类」可在标签间迁移。
- **统一 7 档估值结论**：所有基金类型都给出细分结论，可直接横比：
  `严重高估 / 高估 / 估值偏高 / 合理 / 估值偏低 / 低估 / 严重低估`；
  股票 / 混合 / 指数类另附动能细节（良性上涨、上涨尾声、极端涨跌、连跌加速等），
  债券 / 货币类只补「回撤关注」。
- **指数基金额外看市盈率**：指数 / ETF 类基金自动抓取「跟踪指数」的市盈率(TTM)历史分位，
  作为基本面估值维度（与净值历史分位互为印证）；主动股票 / 混合基金没有统一市盈率，仍以净值历史分位为代理。
- **可交互走势图（`走势图.html`）**：基于 ECharts，**上图=净值相关、下图=估值分位**；
  顶部新增 **From / To 日期筛选框**（默认全部历史，上下两图滑块联动同步）；
  支持**拖动滑块 / 滚轮缩放日期区间**、点击图例开关均线（MA20 / MA120）与高·低估线；
  估值分位图 y 轴反向（越往上越贵）。断网时可用同目录静态图 `历史趋势.png`。
- **默认抓最新**：每次分析都联网抓取最新净值；断网时勾「离线模式」只读本地缓存。
- **数据记忆**：跑过的「上次更新 / 最新净值 / 估值结论」记录在 `funds.json`，跨会话保留。
- **名单以 `funds.json` 为唯一权威源**：UI 增删改直接写回 `funds.json`；你也可以直接编辑
  `funds.json` 手动增删基金，下次打开或点「刷新名称」自动生效。

## 使用

```bash
pip install -r requirements.txt
python gui.py
```

- 名单只存于 `funds.json`（唯一权威源），不再使用 txt 名单文件。
- 添加基金：填 6 位代码 →「查询名称」自动补全（含类型）→ 选分类 → 确定。
- 分析：多选基金后点「开始分析选中」；单选一只可「设今日预测」。
- 分类管理：点「🏷 管理分类」改名 / 新增 / 删除空标签；选中基金后点「🔁 转移分类」在标签间迁移。
  分类标签存于 `categories.json`。
- 查看：双击列表某行，或选中后点「打开报告」，浏览器打开 `走势图.html`。

命令行单测（无需 GUI）：

```bash
python analysis.py 012414
```

## 持仓成本与浮动盈亏

单选一只基金点「💰 设成本」，填 **成本单价** 与可选的 **持有份额 / 备注**，保存在 `持仓成本.json`
（已加入 `.gitignore`，不随 git 提交）。保存后会自动用本地缓存刷新这一只的报告，不联网、不重抓数据。

**成本为什么按单位净值填？**

- 基金申购实行「未知价」：T 日 15:00 前的申请按 **T 日收盘后公布的单位净值** 确认份额，
  成交价就是单位净值，所以成本单价自然是单位净值口径。
- **累计净值 ＝ 单位净值 ＋ 历史累计分红**，是「业绩口径」，用来画走势以消除分红除权造成的假跌，
  **不是成交价**。拿累计净值当成本，等于把历年分红也算进你的投入，凭空虚增/扭曲盈亏。
  例：`050011` 单位净值 `3.5198`、累计净值 `3.6348`，差的 `0.1150` 就是累计分红。
- 更严谨的「成本单价」＝ **总投入本金 ÷ 持有份额**（含申购费、多次买入加权平均），
  建议直接填这个摊薄后的均价。

**盈亏怎么算**：`(最新单位净值 ÷ 成本单价 − 1)`；填了份额再算 `(最新单位净值 − 成本单价) × 份额`。

- 未计手续费、未计 **现金分红**（份额不变、钱已落袋，实际总收益会高于此处数字）。
- **红利再投**会增加份额并摊低成本单价，请回来更新份额。
- 静态兜底图 `历史趋势.png` 画的是累计净值，口径不同，因此**没有**画成本线；
  成本线只在可交互 `走势图.html` 里，对应「单位净值」那条线。

统计参考，非投资收益承诺。

## 近期价格通道：为什么给两个口径

报告顶部横幅用**同样的算法**（近 250 交易日、15%~35% 分位＝相对低位区、65%~85% ＝相对高位区）
分别对「累计净值」和「单位净值」各算一遍，并列显示：

| 口径 | 用途 | 注意 |
| --- | --- | --- |
| 累计净值 | **判断当前价在近期分布的哪一段**（主口径） | 分红除权不会让它向下跳空；但它只是把每份分红**简单加回**，未按除权日再投复利，不是严格复权净值 |
| 单位净值 | **和你的成本价、App 里看到的净值直接对照** | 窗口内若有分红，曲线会跳空失真，只作数字参考，不拿来判高低 |

- 两者差额就是历史每份累计分红。例：`012414` 累计 `0.6621`、单位 `0.5771`，差 `0.0850`。
- 无分红史的基金两者数值完全相同，横幅会注明「数值一致」，不重复刷屏。
- 窗口内发生分红 / 份额折算时会额外提示。个别老分级基金（如 `161720`）数据源里
  累计净值反而低于单位净值，绝对数值可能失真，通道只看相对位置。
- 通道描述的是**过去一段时间价格落在哪个区间**，不是未来目标价、不是买卖指令，会随行情滚动。

## 估值结论怎么读

**估值分位** = 历史上净值「高于」今日的交易日占比：
值越大 → 今日越接近历史低位（越便宜）；值越小 → 越接近历史高位（越贵）。

结论在「高估线（历史 10% 分位，小值=贵）」与「低估线（历史 90% 分位，大值=便宜）」之间细分为 7 档：

| 区间 | 结论 |
|---|---|
| 估值分位 ≤ 高估线（且很极端） | **严重高估** |
| 估值分位 ≤ 高估线 | **高估** |
| 高估线 < 估值分位 ≤ 合理区上半 | **估值偏高**（偏贵） |
| 合理区中部 | **合理** |
| 合理区下半 < 估值分位 < 低估线 | **估值偏低**（偏便宜） |
| 估值分位 ≥ 低估线 | **低估** |
| 估值分位 ≥ 低估线（且很极端） | **严重低估** |

> 说明：本工具给出的是「规则式参考信号」，并非回测验证过的交易策略。
> 长期上涨的股票 / 指数基金，全历史估值分位可能长期偏低（总显「高估」），
> 此时看「近 60 日(短期)估值分位」更接近短期状态。
> **指数 / ETF 基金**额外给出「跟踪指数 PE 分位」：PE 分位越大=指数越便宜，可与净值分位交叉印证；
> 主动股票 / 混合基金没有统一市盈率，仅以净值历史分位为代理。
> 债券 / 货币类波动小，「高估 / 低估」仅表示相对自身历史的位置，不等于买卖建议。

## 跨平台

- Windows / macOS 均已验证可用；图表中文字体按平台自动选择（Win=雅黑，macOS=PingFang）。
