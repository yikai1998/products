# 基金走势分析（个人理财）

一个用于分析公募基金走势的小工具：自动抓取净值 / 持仓 / 基本信息，计算均线、历史估值分位、
回撤、连涨连跌等因子，给出**统一的「7 档估值结论」**（严重高估 / 高估 / 估值偏高 / 合理 /
估值偏低 / 低估 / 严重低估，适用于所有类型基金），并用图形界面管理自选基金、批量分析、
生成带日期筛选的可交互走势图。

## 功能

- **图形界面（`gui.py`）**：增 / 删自选基金、分类（持仓 / 临时 / 自选 / 观察 / 其它）；
  单只基金设「今日预测涨幅」；一键批量或单只分析（后台线程，界面不卡）；
  列表直接看「类型 / 最新净值 / 估值分位 / 估值结论 / 预测% / 上次更新」；双击打开报告。
- **分类标签可改名 / 转移**：点「🏷 管理分类」可直接改标签名、新增标签、删除空标签
  （改名会同步改掉对应 `基金代码名单_*.txt` 文件名）；选中基金后点「🔁 转移分类」可在标签间迁移。
- **统一 7 档估值结论**：所有基金类型都给出细分结论，可直接横比：
  `严重高估 / 高估 / 估值偏高 / 合理 / 估值偏低 / 低估 / 严重低估`；
  股票 / 混合 / 指数类另附动能细节（良性上涨、上涨尾声、极端涨跌、连跌加速等），
  债券 / 货币类只补「回撤关注」。
- **指数基金额外看市盈率**：指数 / ETF 类基金自动抓取「跟踪指数」的市盈率(TTM)历史分位，
  作为基本面估值维度（与净值历史分位互为印证）；主动股票 / 混合基金没有统一市盈率，仍以净值历史分位为代理。
- **可交互走势图（`走势图.html`）**：基于 ECharts，**上图=净值相关、下图=估值分位**；
  顶部新增 **From / To 日期筛选框**（默认全部历史，上下两图滑块联动同步）；
  支持**拖动滑块 / 滚轮缩放日期区间**、点击图例开关均线（MA20 / MA120）与高·低估线；
  估值分位图 y 轴反向（越往上越贵）。断网时可用同目录静态图 `历史趋势.png`。
- **默认抓最新**：每次分析都联网抓取最新净值；断网时勾「离线模式」只读本地缓存。
- **数据记忆**：跑过的「上次更新 / 最新净值 / 估值结论」记录在 `funds.json`，跨会话保留。
- **自选名单双向同步**：UI 增删改会写回 `基金代码名单_{分类}.txt`；手动在 txt 加代码，
  下次打开 UI 也会读进来。

## 使用

```bash
pip install -r requirements.txt
python gui.py
```

- 首次运行会自动把旧的 `基金代码名单_*.txt` 并入 `funds.json`。
- 添加基金：填 6 位代码 →「查询名称」自动补全（含类型）→ 选分类 → 确定。
- 分析：多选基金后点「开始分析选中」；单选一只可「设今日预测」。
- 分类管理：点「🏷 管理分类」改名 / 新增 / 删除空标签；选中基金后点「🔁 转移分类」在标签间迁移。
  分类标签存于 `categories.json`，同名 txt 会随之改名。
- 查看：双击列表某行，或选中后点「打开报告」，浏览器打开 `走势图.html`。

命令行单测（无需 GUI）：

```bash
python analysis.py 012414
```

## 估值结论怎么读

**估值分位** = 历史上净值「高于」今日的交易日占比：
值越大 → 今日越接近历史低位（越便宜）；值越小 → 越接近历史高位（越贵）。

结论在「高估线（历史 10% 分位，小值=贵）」与「低估线（历史 90% 分位，大值=便宜）」之间细分为 7 档：

| 区间 | 结论 |
|---|---|
| 估值分位 ≤ 高估线（且很极端） | **严重高估** |
| 估值分位 ≤ 高估线 | **高估** |
| 高估线 < 估值分位 ≤ 合理区上半 | **估值偏高**（偏贵） |
| 合理区中部 | **合理** |
| 合理区下半 < 估值分位 < 低估线 | **估值偏低**（偏便宜） |
| 估值分位 ≥ 低估线 | **低估** |
| 估值分位 ≥ 低估线（且很极端） | **严重低估** |

> 说明：本工具给出的是「规则式参考信号」，并非回测验证过的交易策略。
> 长期上涨的股票 / 指数基金，全历史估值分位可能长期偏低（总显「高估」），
> 此时看「近 60 日(短期)估值分位」更接近短期状态。
> **指数 / ETF 基金**额外给出「跟踪指数 PE 分位」：PE 分位越大=指数越便宜，可与净值分位交叉印证；
> 主动股票 / 混合基金没有统一市盈率，仅以净值历史分位为代理。
> 债券 / 货币类波动小，「高估 / 低估」仅表示相对自身历史的位置，不等于买卖建议。

## 跨平台

- Windows / macOS 均已验证可用；图表中文字体按平台自动选择（Win=雅黑，macOS=PingFang）。
- 打开报告目录：Windows 用 `explorer`，macOS 用 `open`，Linux 用 `xdg-open`。
- Linux 需自行安装 `python3-tk`（tkinter 依赖）。

## 数据来源

净值 / 持仓 / 基本信息来自 [AkShare](https://akshare.akfamily.xyz/)（东方财富 / 雪球等公开接口）。
接口名称可能随版本变动，如遇抓取失败请核对 akshare 当前版本。
